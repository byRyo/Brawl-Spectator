# Brawl Spectator

A small Brawl Stars Frida project that allows you to spectate players directly using their player tag.

It supports:

* Normal spectating
* Brawl TV spectating
* Player tag input

## About

This is an old project I made a while ago. The code isn't particularly clean and the original project is no longer on my PC, so I decided to make what I still had public instead of letting it disappear.

The project is free to use, modify, and improve.

It was made for an older Brawl Stars version, so offsets and internal functions may need to be updated for newer versions.
